DICA 01
RACIOCÍNIO LÓGICO - DICAS E PEGADINHAS[cite: 1]
  • Não confunda fato com opinião. Adjetivos como "excelente", "péssimo", "melhor" costumam indicar opinião.[cite: 1]
  • Correlação não significa causalidade. Dois eventos ocorrerem juntos não prova que um causou o outro.[cite: 1]
  • Ataque à pessoa (ad hominem) não invalida o argumento apresentado.[cite: 1]
  • Apelo à maioria ("todo mundo faz", "a maioria acredita") não comprova a verdade de uma afirmação.[cite: 1]
⚠️
ATENÇÃO!! Desconfie de palavras absolutas como "sempre", "nunca", "todos", "ninguém" e "obrigatoriamente".[cite: 1]
📌
IMPORTANTE: Generalização apressada é uma das falácias mais cobradas: poucos casos não justificam uma regra geral.[cite: 1]
🔎
OBS.: Em questões sobre fortalecimento e enfraquecimento de argumentos, procure evidências que eliminem ou apresentem explicações alternativas. Leia primeiro a conclusão do argumento e só depois identifique as premissas.[cite: 1]

DICA 02
INFORMÁTICA - NOÇÕES GERAIS E COMPUTADOR[cite: 2]

O computador é uma máquina capaz de executar tarefas de forma automática e rápida.[cite: 2] Ele enxerga os dados como combinações de 1s e 0s e os combina para formar mídias complexas (fotos, vídeos, sites).[cite: 2]

ESQUEMATIZANDO: PARTES DO COMPUTADOR
COMPUTADOR[cite: 2]
HARDWARE (Parte Física)[cite: 2]
SOFTWARE (Parte Lógica)[cite: 2]
Ex.: Hardware é a parte física do computador, é tudo que pode ser tocado com as mãos (Monitor, Teclado, Placa-mãe).[cite: 2] Software são os programas e sistemas operacionais que permitem o funcionamento (Windows).[cite: 2]
DICA 03
COMPONENTES DE HARDWARE[cite: 2]

Os hardwares são divididos em 4 elementos centrais:[cite: 2]

  • Dispositivos de entrada: inserem dados no PC (ex.: teclado, mouse).[cite: 2]
  • Dispositivos de saída: traduzem dados para o usuário (ex.: monitor, caixa de som).[cite: 2]
  • Componentes internos: se conectam para fazer o PC funcionar (ex.: processador, placa-mãe).[cite: 2]
  • Armazenamento secundário: guardam dados permanentemente (ex.: HD, Pen-drive).[cite: 2]
COMPONENTE[cite: 3] DESCRIÇÃO PRINCIPAL[cite: 3]
Placa-Mãe (Motherboard)[cite: 3] Placa central de todo o computador, onde todos os outros componentes são conectados.[cite: 3]
Processador (CPU)[cite: 3] Fica acoplado à placa-mãe e é responsável por fazer o controle das operações. Interfere diretamente na rapidez.[cite: 3]
Memória RAM[cite: 3] Armazena momentaneamente os dados de programas em execução.[cite: 3]
Disco Rígido (HD)[cite: 3] Armazena dados e arquivos permanentemente.[cite: 3]
DICA 04
PLACA-MÃE E BARRAMENTOS[cite: 4]

A Placa-Mãe possui conectores e componentes essenciais:[cite: 4]

  • Chipset: Controla vários componentes da placa-mãe.[cite: 4] Dividido em Ponte Sul (dispositivos de E/S) e Ponte Norte (memórias e barramentos de vídeo).[cite: 4]
  • Soquete (Socket): Local onde deve ser encaixado o processador (CPU).[cite: 4]
  • Bateria de Lítio: Mantém o relógio interno e as informações dentro da memória ROM enquanto o computador está desligado.[cite: 4]
🧠
MEMORIZE OS BARRAMENTOS (Vias de comunicação):
[cite: 4] ➔ ISA: Antigo, para placas de expansão (som, rede, vídeo).[cite: 4]
➔ PCI / PCI-Express: Placas de expansão, usa a tecnologia "Plug and Play".[cite: 5]
➔ AGP: Utilizado somente para placas de vídeo.[cite: 5]
➔ IDE / SATA: Utilizado para unidades de armazenamento internas (discos rígidos, cd's, DVD).[cite: 5]
📌
IMPORTANTE: O BIOS (Sistema Básico de Entrada/Saída)[cite: 4] é um aplicativo destinado a realizar algumas tarefas básicas no momento em que o computador é ligado.[cite: 4] Ele faz a verificação de todos os hardwares e carrega o sistema operacional.[cite: 4] Não é possível desinstalar o BIOS do computador, apenas atualizá-lo.[cite: 9]
DICA 05
ARMAZENAMENTO: HD x SSD[cite: 7]
CARACTERÍSTICA[cite: 7] HD (Hard Disk Drive)[cite: 7] SSD (Solid-State Drive)[cite: 7]
Funcionamento[cite: 7] Disco magnético e peças mecânicas (rotação de 5.400 e 7.200 RPM).[cite: 7] Eletrônico (memória flash), sem partes móveis.[cite: 7]
Desempenho / Barulho[cite: 7] Mais lento e gera maior barulho.[cite: 7] Muito mais rápido e silencioso (menor barulho).[cite: 7]
Resistência Física[cite: 7] Menor.[cite: 7] Maior.[cite: 7]
Ex.: Ambos são de armazenamento não volátil[cite: 7] (não perdem os dados ao desligar o PC).
DICA 06
CLASSIFICAÇÃO DE MEMÓRIAS[cite: 7, 8]
ESQUEMATIZANDO: TIPOS DE MEMÓRIA[cite: 7, 8]
RAM: Volátil e rápida.[cite: 7] Somente fica ativa enquanto o computador estiver ligado.[cite: 7] (Ex: SRAM e DRAM).[cite: 7, 8]
ROM: Memória Somente de Leitura, não volátil (armazena os dados permanentemente).[cite: 8]
CACHE: Acesso randômico mais rápida que armazena os dados mais utilizados pelo processador[cite: 8] (L1 e L2).[cite: 8]
DICA BÔNUS
SISTEMAS, ARQUIVOS E SOFTWARES[cite: 8, 9]
  • Software Básico: Fazem o computador funcionar como a linguagem de programação e o Sistema operacional.[cite: 9]
  • Software Aplicativo: Tem uma função auxiliar para tornar sua vida mais fácil.[cite: 9] Ex: navegadores, planilhas, Word, antivírus.[cite: 9]
🔎
OBS.: No Windows, pastas organizam os arquivos[cite: 9] e Atalhos (ícones com uma flecha)[cite: 9] são uma maneira rápida de abrir um arquivo.[cite: 9] Apagá-los não exclui o arquivo original![cite: 9]

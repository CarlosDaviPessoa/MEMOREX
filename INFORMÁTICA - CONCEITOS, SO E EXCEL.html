DICA 01

ARMAZENAMENTO: ARQUIVOS, PASTAS E ATALHOS

Quando produzimos um trabalho em um computador, precisamos armazená-lo. Para isso utilizamos o arquivo eletrônico (ou arquivo), que é a estrutura lógica para guardar nossos dados. Para fins de organização, os arquivos são guardados em pastas ou diretórios.

📌
IMPORTANTE: O ato de guardar um arquivo no computador é denominado salvamento. Diferente do papel físico, um arquivo eletrônico pode ser alterado e impresso quantas vezes for necessário.
  • Pastas/Diretórios: Não contêm informação propriamente dita, mas sim arquivos ou mais pastas. Organizam tudo o que está dentro das unidades (HD, SSD, Pen Drive).
  • Arquivos: É a unidade básica de armazenamento. Podem ser textos, músicas, vídeos ou imagens. Além disso, arquivos executáveis e bibliotecas (como as DLL) são vitais para o funcionamento do sistema.
  • Atalhos: É uma maneira rápida de abrir um arquivo, pasta ou programa. Não tem conteúdo algum, apenas "chama" o arquivo original armazenado em outro lugar. Identificamos um atalho por uma seta no canto inferior esquerdo do ícone.
⚠️
ATENÇÃO!! Se você apagar um atalho, não apaga o arquivo! O arquivo original fica intacto.

Nomes e Extensões de Arquivos: Todo arquivo possui um nome (obrigatório, até 256 caracteres em regra) e uma extensão (separada por ponto). A extensão indica ao Sistema Operacional qual programa deve ser usado para abri-lo.

DICA 02

BIBLIOTECAS DO WINDOWS E UNIDADES

As Bibliotecas servem para centralizar em um mesmo local arquivos de várias pastas diferentes (ex.: agrupar músicas que estão no C: e no D: numa mesma visualização).

⚠️
CUIDADO NA PROVA! Diferente do atalho, se você apagar um arquivo por meio de uma biblioteca, o arquivo original será apagado do computador.
  • Partição: São divisões lógicas criadas a partir de um único espaço físico (ex.: dividir um HD em C: e D:).
Ex.: Em "Meu Computador" ou "Este Computador", podemos ver C: para o Disco Rígido Principal e D: para uma unidade de CD ou partição extra.
DICA 03

SOFTWARE E SUAS CLASSIFICAÇÕES

Um programa de computador (software) é a parte lógica/funcional da máquina. Pode ser classificado em três tipos essenciais:

ESQUEMATIZANDO: TIPOS DE SOFTWARE
SOFTWARE
BÁSICO: Faz o PC funcionar (ex.: Sistema Operacional, BIOS, Linguagens).
APLICATIVO: Função útil ao usuário (ex.: Word, Excel, Navegadores, Skype).
UTILITÁRIO: Complementam o sistema (ex.: Antivírus, Desfragmentador).
🧠
MEMORIZE: O BIOS é gravado em memória ROM. Ele nunca pode ser desinstalado, apenas atualizado.

Softwares utilitários podem ter função Preventiva (Antivírus, Atualizações) ou Corretiva (Formatação, Scandisk).

DICA 04

LICENCIAMENTO E RELAÇÃO HARDWARE VS SOFTWARE

  • Freeware: Software 100% gratuito sem restrição de funções.
  • Shareware: Gratuito, mas com limitações de tempo ou funções (para testar). Paga-se para desbloquear.
  • Adware: Requer que o usuário visualize propagandas para ser usado sem pagar.
  • Open Source (Código Aberto): Software livre, gratuito, e com código-fonte aberto para edição.
ESQUEMATIZANDO: HARDWARE VS SOFTWARE
CARACTERÍSTICA HARDWARE (Físico) SOFTWARE (Lógico)
O que é? Elementos físicos que formam o equipamento. Programas que fazem a máquina funcionar.
Tempo de Vida Pode estragar/desgastar com o tempo. Pode ficar desatualizado (obsoleto).
Manutenção Substituição de peças (placas, memória). Pode ser reinstalado, corrigido, atualizado.
DICA 05

GERENCIAMENTO DE ARQUIVOS (EXPLORADOR)

O gerenciamento envolve organizar, copiar e excluir dados. A ferramenta nativa para isso é o Explorador de Arquivos (antigo Windows Explorer).

📌
IMPORTANTE: Para abrir rapidamente o Explorador, use o atalho Windows + E.

Navegação e Comandos Vitais:

  • Criar Nova Pasta: O atalho supremo de prova é Ctrl + Shift + N.
  • Renomear: Selecione e aperte F2. Renomear não altera o conteúdo do arquivo.
  • Copiar (Ctrl + C): Mantém o original na origem e cria uma duplicata no destino ao Colar (Ctrl + V).
  • Recortar / Mover (Ctrl + X): O arquivo deixa de existir na origem e é transferido para o destino após o Colar.
⚠️
ARRASTAR E SOLTAR (PEGADINHA!):
➔ Arrastar para a mesma unidade (ex: C: para C:) = MOVER.
➔ Arrastar para unidades diferentes (ex: C: para Pendrive) = COPIAR.
➔ Exceção: Arrastar pressionando Ctrl sempre irá COPIAR, e pressionando Shift sempre irá MOVER.
DICA 06

EXCLUSÃO, LIXEIRA E DESFAZER AÇÕES

A Lixeira do Windows armazena temporariamente os arquivos apagados, permitindo restaurá-los.

  • Exclusão Normal (Delete): Envia o arquivo para a Lixeira.
  • Exclusão Definitiva (Shift + Delete): Apaga o arquivo sem passar pela lixeira.
  • Desfazer Ação (Ctrl + Z): Desfaz ações como exclusão (caso não tenha usado Shift), renomeação ou movimentação acidental.
🧠
RESUMO DE OURO DOS ATALHOS:
Ctrl + A = Selecionar Tudo | Ctrl + C = Copiar | Ctrl + X = Recortar (prepara p/ mover)
F5 = Atualizar | F2 = Renomear | Alt + Tab = Alternar janelas
DICA 07

SISTEMAS OPERACIONAIS - FUNDAMENTOS E EXEMPLOS

O Sistema Operacional (SO) é o software BÁSICO essencial. Ele atua como elo entre o usuário e o hardware. Você não precisa obrigatoriamente usar Windows, mas precisa de algum SO.

  • Windows: Interface gráfica amigável, comercial (proprietário), alvo de muitos vírus por ser o mais popular.
  • Linux: Código aberto (Open Source), gratuito, mantido por desenvolvedores no mundo todo, praticamente imune a vírus comuns de PC.
  • Mac OS: Sistema da Apple. Exclusivo de computadores Mac. Alto desempenho, pago e proprietário.
  • Android: Sistema móvel da Google (baseado em Linux, código aberto).
  • iOS: Sistema móvel da Apple (proprietário, exclusivo do iPhone e iPad).

DICA 09

SISTEMAS MÓVEIS (ANDROID) E SEGURANÇA

Dispositivos móveis combinam processamento, armazenamento e conexão. O Android é líder de mercado.

  • Conexões: Wi-Fi (Internet sem fio), Bluetooth (comunicação de curta distância), GPS (localização geográfica).
  • Modo Avião: Desativa conexões de rede celular, Wi-Fi e Bluetooth simultaneamente.
  • Atualização do Sistema: Corrige falhas, traz recursos novos e melhora a segurança.
  • Backup e Conta: Utiliza primariamente a Conta Google para cópia de segurança (fotos, contatos, apps). Permite recuperação em caso de perda ou troca.
  • Restauração de Fábrica: Devolve o aparelho às configurações iniciais e apaga todos os dados pessoais do usuário. (Faça backup antes!).
🧠
MACETE ANDROID:
Android = Linux + Google + Aberto + Play Store
iOS = Apple + Proprietário + Exclusivo iPhone/iPad
Criar Pasta no Android = Arrastar um ícone de aplicativo sobre outro.

(Prefeitura de Criciúma - Agente Comunitário - 2019) O sistema Android possibilita que seus usuários possam agrupar seus aplicativos em pastas de acordo com sua necessidade. Qual a ação necessária para a criação de uma pasta no Android?

  1. Pressionar com o dedo na tela e manter pressionado até o aparecimento do menu pasta, posteriormente clicar em nova pasta.
  2. Arrastar um aplicativo e sobrepô-lo a outro.
  3. Pressionar o botão menu e acessar as configurações.

DICA 10

PLANILHAS ELETRÔNICAS: MS EXCEL

O Microsoft Excel é um editor de planilhas eletrônicas. Uma planilha organiza dados para realizar cálculos lógicos, gráficos e relatórios.

  • Colunas: Formam o eixo vertical e são identificadas por Letras (A, B, C...).
  • Linhas: Formam o eixo horizontal e são identificadas por Números (1, 2, 3...).
  • Células: É a intersecção de uma coluna com uma linha (Ex.: A1, C5). É aqui que escrevemos textos, valores e fórmulas. O nome da célula é exibido na "Caixa de Nome".
🔎
OBS.: O pacote gratuito que rivaliza com o Office é o LibreOffice (ou OpenOffice). O equivalente ao Excel nele é o Calc, e o do PowerPoint é o Impress.
DICA BÔNUS

MS EXCEL: GUIA PÁGINA INICIAL E SEUS BLOCOS

Na guia principal ("Página Inicial"), as ferramentas são separadas em blocos (grupos) estratégicos:

ESQUEMATIZANDO: BLOCOS DA PÁGINA INICIAL DO EXCEL
ÁREA DE TRANSFERÊNCIA: Cortar, Copiar, Colar e o fundamental botão "Colar Especial".
FONTE: Negrito, Itálico, Tamanho, Cor da letra e Cor de Fundo da Célula.
ALINHAMENTO: Alinhar textos. Destaque: botão Mesclar e Centralizar (junta células).
NÚMERO: Define formato do dado (Data, Moeda, Porcentagem, Texto, Hora).
ESTILO: Ferramenta avançada de Formatação Condicional (muda a cor da célula baseado em regras lógicas, ex.: notas baixas em vermelho).
CÉLULAS e EDIÇÃO: Inserir/Excluir células, redimensionar; Atalhos para Autosoma (Σ), Classificar e Filtrar.
Ex.: Na Formatação Condicional, você pode configurar o Excel para pintar de verde toda célula que tiver a palavra "APROVADO", e de vermelho a que tiver "REPROVADO". Tudo ocorre de forma automática!
